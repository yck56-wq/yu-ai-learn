# 生态环保：

- 修复工作：

  1. 排土场整型   

  2. 土壤改良

  3. 供水系统

  3. 让排土场变成“海绵”

  3. 把“废水”变“活水”

  3. 植被重建

- 低碳转型：煤矿企业应当按照国家规定提升煤炭洗选加工水平，提高原煤入选率。

- 30.60目标：中国承诺在2030年前实现碳达峰，并在2060年前实现碳中和。这一目标是在2020年9月的第75届联合国大会上由国家主席习近平提出的。

- 碳达峰：二氧化碳排放总量达到历史最高点，进入平稳平台期后逐步下降，这个拐点就是碳达峰 。

- 碳中和：特定周期内，人类活动产生的二氧化碳，通过节能减排、植树造林、碳捕捉、碳汇、碳抵消等方式全部吸收中和，实现二氧化碳净排放为零 。
