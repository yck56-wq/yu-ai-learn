# 私有知识库运行说明

## 配置

后端新增 `EMBEDDING_API_KEY`、`EMBEDDING_MODEL`、`KNOWLEDGE_STORAGE_DIR`、`CHROMA_PERSIST_DIRECTORY` 以及知识库大小、文本和切片上限。Embedding 密钥只放在后端 `.env`，不要写入小程序配置或日志。

默认原始文件保存在 `backend/uploads/knowledge/<user_id>/`，Chroma 保存在 `backend/data/chroma/`。部署时需要为这两个目录准备持久化磁盘并限制访问权限。

## 数据库

先执行 `sql/001_user_system.sql`，再执行 `sql/002_private_knowledge_base.sql`。后者会幂等补充题库来源字段并创建 `knowledge_documents` 表。测试库可运行 `..\\.venv-user\\Scripts\\python.exe -m tests.prepare_mysql` 准备。

## 上传限制和行为

首版只接受 PDF、DOCX、Markdown。上传请求同步完成解析、切分、Embedding、Chroma 写入和元数据保存；任一步失败都会删除临时文件、向量和数据库记录。每个用户使用独立 collection，检索、列表和删除都绑定当前登录用户。

## 前端边界

微信小程序通过 `chooseMessageFile` 正式上传。H5 只展示页面预览，不伪造上传成功；正式验证需要在微信开发者工具中完成。

配置真实 DashScope Embedding 后，用两个账号分别上传资料，确认列表和出题互不可见；删除后检索不到对应片段；重启后列表和索引仍可用。验收记录只写结果和错误类别，不记录密钥、Token、完整文件内容或绝对路径。
