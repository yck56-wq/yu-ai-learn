# 出题重复问题修复

原因：旧服务吞掉模型异常，然后循环复制同一题作为成功响应。

修改：删除本地重复模板；显式使用 DeepSeek JSON Object 模式；提示词规划不同知识点；校验题量、题干与近似题干、完整选项、有效答案和知识点覆盖。质量失败和临时服务故障最多重试一次，仍失败返回非成功状态。鉴权/配置错误不伪装为成功。

验证：17 项 pytest 通过（仅在 HTTP 边界模拟模型服务，其余经过实际 Prompt、ChatOpenAI、Pydantic、服务层和 API）。一次真实 DeepSeek 调用成功返回 5 道不同题，覆盖检索方案、嵌入、切分、引用和时效性。实际测试使用本地配置，未输出密钥。

文字相似度校验不能保证识别所有语义重复；提示词增加知识点覆盖要求作为补充，不声称完全解决模型知识质量问题。

文档依据：https://api-docs.deepseek.com/guides/json_mode
