## Purpose

让题目生成 Agent 能够在用户私有文档和现有联网资料之间选择合适的数据源，并把可追溯来源绑定到题目与历史题库中。

## ADDED Requirements

### Requirement: Agent 可以选择私有知识库或联网资料

系统 SHALL 在生成题目前同时提供当前用户私有知识检索和现有联网检索能力；Agent 可以选择任一来源或组合来源，私有检索不得跨越当前用户边界。

#### Scenario: 私有文档命中
- **WHEN** 用户已有相关私有文档且输入问题与文档内容相关
- **THEN** Agent 使用私有检索结果生成题目，并返回私有文档来源元数据

#### Scenario: 私有文档与联网资料组合
- **WHEN** 用户输入同时需要内部资料和外部背景
- **THEN** Agent 可以同时使用两类检索结果，题目来源列表明确区分来源类型

#### Scenario: 没有私有文档
- **WHEN** 当前用户没有已就绪的私有文档
- **THEN** 私有检索工具返回空结果，现有联网或 fallback 出题路径继续工作

#### Scenario: 检索服务异常降级
- **WHEN** 私有向量检索或联网检索超时、配置缺失或暂时失败
- **THEN** 系统记录脱敏错误并按现有降级策略继续生成；不得伪造私有来源或跳过原有题目质量校验

### Requirement: 题目必须绑定可验证来源

系统 SHALL 在成功使用检索资料时为题库保存来源快照，并要求每道题的来源 ID 来自本轮实际检索结果；无法由来源支持的关键断言 MUST 被拒绝或重新生成。

#### Scenario: 生成带私有来源的题库
- **WHEN** Agent 返回引用私有文档片段的合格题库
- **THEN** 响应和持久化快照包含来源类型、文档 ID、文件名、片段或页码等信息，且题目 `source_ids` 可追溯到来源列表

#### Scenario: 模型引用未知来源
- **WHEN** 模型输出的 `source_ids` 不存在于本轮来源列表
- **THEN** 系统拒绝该结果并执行有限重试，重试仍失败时返回明确的题目质量错误

#### Scenario: 题目缺少证据支持
- **WHEN** 题干、选项、答案、讲解或知识点包含来源片段无法支持的关键断言
- **THEN** 系统不得将该题库作为成功结果返回

### Requirement: 新来源字段兼容现有题库流程

系统 SHALL 保留现有 `questions`、题型、题量、答案和鉴权契约；来源、检索状态和私有来源字段 MUST 为可选扩展，旧客户端仍可完成答题和报告结算。

#### Scenario: 旧客户端收到带来源题库
- **WHEN** 旧版本客户端收到包含 `sources` 和 `source_ids` 的题库
- **THEN** 客户端忽略新增字段后仍能按原有 `questions` 完成答题

#### Scenario: 历史题库回看
- **WHEN** 用户查看已完成题库的历史报告
- **THEN** 系统读取生成时保存的来源快照，不依赖再次联网或当前向量库状态
