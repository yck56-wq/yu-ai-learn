## Purpose

让 AI 题目建立在可追溯的近期资料上，降低新知识主题因模型训练时限、主题歧义或领域混淆而产生错误题目的风险。

## ADDED Requirements

### Requirement: Agent 必须为需要外部资料的主题选择获取方式

系统 SHALL 在生成题目前判断用户输入是普通主题、复杂/时效主题、URL 或混合输入，并在 Tavily Search 与 Tavily Extract 之间选择；Search 必须同时提供轻量摘要和深度原文两种可选配置。对于可能依赖近期知识的主题，系统必须先尝试获取外部资料，成功时将通过基本质量校验的资料作为出题依据，异常时按降级要求使用原 Prompt。

#### Scenario: 新主题检索成功
- **WHEN** 用户输入一个可能依赖近期知识的主题，且检索服务返回相关资料
- **THEN** 系统基于筛选后的资料生成题库，并在响应中返回资料来源元数据

#### Scenario: 非时效性主题仍可生成
- **WHEN** 用户输入稳定的基础概念，且系统判断不需要近期资料
- **THEN** 系统可以沿用直接出题路径，但仍必须通过现有题量、题型、答案和重复题校验

#### Scenario: 用户输入 URL
- **WHEN** 用户输入包含一个可识别的网页 URL
- **THEN** 系统优先提取该页面内容，并将提取结果作为出题资料；提取失败时返回明确错误或执行一次受限的相关搜索

#### Scenario: 复杂主题选择深度搜索
- **WHEN** 用户输入专业、复杂或明确要求最新的主题
- **THEN** Agent 选择深度搜索并设置适合的搜索深度、时间范围、日期、国家/地区或域名限制，且在获得足够资料后停止调用工具

#### Scenario: 简单主题选择搜索摘要
- **WHEN** 用户输入稳定且简单的知识主题
- **THEN** Agent 可以选择轻量 Search 配置获取摘要，减少不必要的原文抓取

### Requirement: 来源必须可追溯且与主题相关

系统 SHALL 为每条采用的资料保留标题、规范化 URL、来源名称、摘要或摘录、发布时间（若可得）和抓取时间，并在生成题库中返回来源列表；系统 MUST 去除重复 URL 和明显无关资料。

#### Scenario: 有来源时返回来源信息
- **WHEN** 题库生成成功
- **THEN** 若本轮检索成功，响应包含非空 `sources` 列表，每条来源至少包含 `title`、`url`、`publisher` 和 `snippet`；若发生检索异常并降级，`sources` 可为空或省略

#### Scenario: 来源不足
- **WHEN** 检索结果为空、全部无关或无法形成最低证据集
- **THEN** 系统记录来源不足并继续使用原 Prompt、无搜索上下文生成题目；生成结果仍必须通过现有结构和质量校验

### Requirement: 题目内容必须受证据约束

系统 SHALL 要求题干、选项、答案、讲解和知识点均能由检索资料支持，并通过题目级来源 ID 建立对应关系；无法从资料确认的内容 MUST 被省略、标记为不确定，或使本轮生成失败，不得作为确定事实输出。

#### Scenario: 模型输出偏离资料
- **WHEN** 模型生成的题目包含资料未支持的关键断言或与资料冲突
- **THEN** 系统拒绝该结果并按有限次数重新生成；重试仍失败时返回生成失败错误

#### Scenario: 资料存在相互冲突
- **WHEN** 主要来源对关键事实给出不一致说法
- **THEN** 系统不得静默选择一方作为确定答案，应要求模型明确限定来源/时间范围或拒绝生成相关题目

### Requirement: 失败状态必须区分且不泄露敏感信息

系统 SHALL 区分输入无效、主题歧义、检索失败、来源不足、模型服务失败和题目质量校验失败；错误响应不得包含 API 密钥、完整模型输出或内部请求凭证。

#### Scenario: 检索服务暂时不可用
- **WHEN** 外部检索服务超时或返回暂时性错误
- **THEN** 系统捕获异常并记录不含敏感信息的日志，继续使用原 Prompt、无搜索上下文生成题目；生成结果仍必须通过现有结构和质量校验

#### Scenario: 恶意输入要求忽略约束
- **WHEN** 用户输入包含要求模型忽略来源或改变出题规则的指令
- **THEN** 系统将其视为学习内容而非系统指令，继续执行来源、结构和质量校验

#### Scenario: 检索增强失败
- **WHEN** Agent 或 Tavily 搜索/提取失败
- **THEN** 系统记录检索失败原因并继续调用原出题 Prompt；响应可不包含来源列表，但不得跳过题量、答案、重复题和安全校验

### Requirement: 兼容现有题库和前端答题流程

系统 SHALL 保留现有 `questions` 结构、题量范围、题型、答案格式、重复题校验和鉴权约束；新增来源和检索状态字段 MUST 采用向后兼容的可选扩展。

#### Scenario: 现有客户端读取新题库
- **WHEN** 旧版客户端收到带有 `sources` 的题库响应
- **THEN** 客户端仍可使用原有 `questions` 字段完成答题

#### Scenario: 服务端保存来源快照
- **WHEN** 题库生成成功并持久化
- **THEN** 系统保存生成时使用的来源快照，使历史题库的来源不会因后续检索结果变化而丢失
